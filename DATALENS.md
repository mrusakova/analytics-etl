# Дашборд в DataLens: как собран и как дорабатывать

Данные обновляются раз в сутки в 06:00 МСК (cron, `run_daily.sh`). Долги и записи по группам — снимок каждый понедельник.
Все чарты строятся на представлениях `v_dl_*`: там уже русские названия направлений, классов, статусов и типов отказов.

## 0. Что уже собрано (22.10.2026)
Воркбук **«Ученики — дашборд»** (datalens.ru/workbooks/3b8bv9k8v324m), подключение `kazanmath-base` (кластер analytics, TLS, кэш 1 ч).
Дашборд **«Ученики: выручка, долги, отказы»** — https://datalens.ru/v30a5s9ww0pge-ucheniki-vyruchka-dolgi-otkazy

- Датасеты: Занятия, Ученики, Записи, Долги, Группы по неделям, Обновление данных — поля переименованы по-русски.
- Чарты: Данные обновлены; Выручка по месяцам; Долги по группам (последний снимок); Долги по понедельникам;
  Отказы по месяцам и типам; Отказы по классам и типам; Учатся сейчас по классам; Записи по группам;
  Посещения по группам и месяцам (+ посещаемость).
- Селекторы (закреплены вверху): **Направление**, **Класс** — «ручной ввод», фильтруют ВСЕ чарты, у датасетов которых
  есть поле с таким же названием. Поэтому поля «Направление» и «Класс» во всех датасетах должны называться одинаково —
  при переименовании фильтр перестанет действовать на чарт.
- Посещаемость, % = IF(Посещения + Пропуски = 0, NULL, Посещения / (Посещения + Пропуски)) — защита от деления на ноль.
Воркбук **«Ученики — списки (закрыто)»** (datalens.ru/workbooks/rzxdz1t2ufjka), подключение `analytics-detailed`.
Дашборд **«Ученики: кому звонить (закрыто)»** — https://datalens.ru/emk3vy8w33c2x-ucheniki-komu-zvonit-zakryto
- Датасеты: Должники (ФИО), Риск оттока (ФИО), Ученики и отказы (ФИО) — на `v_dl_*_named`.
- Таблицы: Должники сейчас (фильтр «Последний снимок» = 1), Риск оттока: кому позвонить, Отказавшиеся (Статус = Отказ).
- Те же закреплённые селекторы «Направление» и «Класс».
- Ещё не сделано: доступ коллегам (п. 5) — выдаёт владелец; селектор периода.

## 1. Два воркбука — из-за персональных данных

| Воркбук | Что внутри | Кому доступ |
|---|---|---|
| **Ученики — дашборд** | цифры без ФИО: выручка, долги, отказы, записи, посещения | коллегам — роль «Просмотр» |
| **Ученики — списки (закрыто)** | списки с ФИО: должники, риск оттока, отказавшиеся | только тем, кто звонит родителям |

В каждом воркбуке своё подключение к БД. Роль «Просмотр» не даёт увидеть пароль подключения и сырые таблицы.

## 2. Подключение (в каждом воркбуке)
Создать → Подключение → **PostgreSQL**:
- Способ: «Выбрать в облаке» → кластер `analytics` (или вручную: хост `rc1d-ce0n1hjnn83lr2qv.mdb.yandexcloud.net`, порт `6432`);
- База `analytics`, пользователь `analytics`, пароль — из `.env` на сервере (`PGPASSWORD`);
- TLS — включить; время жизни кэша — 3600 с (данные всё равно меняются раз в сутки).

## 3. Датасеты

Воркбук «Ученики — дашборд» (без имён):

| Датасет | Представление | Для чего | Показатели (агрегация) |
|---|---|---|---|
| Занятия | `v_dl_lessons` | выручка и посещения по периодам | `revenue`, `visits`, `absences` — сумма; `lesson_date` — дата |
| Ученики | `v_dl_students` | отказы, активные | `user_id` — количество уникальных |
| Записи | `v_dl_joins` | записи по группам сейчас | `is_active` — сумма, `join_id` — количество |
| Группы по неделям | `v_dl_groups_weekly` | динамика записей | `active_joins` — сумма |
| Долги | `v_dl_debts` | долги по понедельникам | `debt`, `overdue_debt` — сумма; `user_id` — количество уникальных |
| Обновление | `v_dl_last_run` | «Данные на …» в шапке | `updated_at` |

Вычисляемое поле в «Занятиях» — **Посещаемость, %**:
`SUM([visits]) / (SUM([visits]) + SUM([absences]))` (формат — процент; уважительные пропуски не входят).

Воркбук «Ученики — списки (закрыто)»: `v_dl_debts_named`, `v_dl_risk_named`, `v_dl_students_named`.

## 4. Страницы дашборда

Селекторы вверху каждой страницы: **Направление** (`direction_name`), **Класс** (`grade_label`), **Группа** (`class_name`),
**Период** (дата: `lesson_date` / `refusal_month` / `snapshot_date`). Чтобы один селектор фильтровал чарты
из разных датасетов — в режиме правки дашборда «Связи» → связать поля с одинаковым именем.

**Выручка и долги**
- Индикатор: выручка за выбранный период (`SUM(revenue)`).
- Столбцы: выручка по месяцам (`lesson_date` → месяц), цвет — направление.
- Линия: долг по понедельникам (`snapshot_date`), две линии — `debt` и `overdue_debt`.
- Таблица: текущие долги по группам — фильтр `is_latest = 1`, строки `class_name`, `SUM(debt)`, число должников.

**Отказы**
- Столбцы с накоплением: X — `refusal_month`, цвет — `refusal_type_name`, Y — уникальные `user_id`; фильтр `status_name = Отказ`.
- Таблица: строки — `grade_label`, столбцы — `refusal_type_name`.
- Индикатор: сейчас учатся (`status_name = Учится`, уникальные `user_id`).

**Записи и посещения**
- Таблица групп: `class_name`, активных записей `SUM(is_active)`, всего записей `COUNT(join_id)`.
- Сводная: строки — `class_name`, столбцы — месяц/неделя `lesson_date`, значения — `SUM(visits)` и «Посещаемость, %».
  Период задаёт пользователь селектором дат.
- Линия: `active_joins` по понедельникам из «Групп по неделям».

**Закрытый воркбук: кому звонить**
- Должники: `v_dl_debts_named`, фильтр `is_latest = 1`, сортировка по `debt`.
- Риск оттока: `v_dl_risk_named` — пропуски за 7 дней (`absences_7d`), последнее посещение.
- Отказавшиеся за месяц: `v_dl_students_named`, фильтр `status_name = Отказ` и `refusal_month`.

## 5. Доступ коллегам
Коллега входит в DataLens со своим Яндекс ID → его добавляют в организацию (Yandex Cloud Organization) →
в воркбуке «Поделиться» / «Права доступа» выдают роль «Просмотр». Закрытый воркбук — отдельно и поимённо.
